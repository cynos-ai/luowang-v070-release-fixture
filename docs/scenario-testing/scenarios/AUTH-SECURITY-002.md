## 目的

确认规格行为 8 中「注册和登录按客户端地址限流」：同一客户端短时间内的过多尝试被限流拒绝。

## 依据

- 规格 `docs/changes/cynos-website-auth/spec.md` 行为 8。
- 实现 `src/server/security/rate-limit.ts` 与 `src/server/app.ts`（注册、登录按客户端地址计数限流）。

## 前置条件

- 隔离的非生产测试环境；
- 可确认限流按客户端地址计数、且不干扰同环境其他场景的观察手段（待确认）。

## 步骤

1. 从同一客户端地址在短时间内连续发起超过阈值的注册或登录尝试。
2. 观察后续请求是否被限流拒绝。

## 期望

- 超过阈值后的尝试被限流拒绝（4xx），不建立会话。

## 需要记录

- 触发限流所需的尝试次数与限流响应。

## 状态说明

候选为 draft：期望依据明确（规格行为 8），但限流按客户端地址计数，受控 HTTP 客户端与部署共享来源地址，触发限流可能影响同环境其他场景；可隔离触发的条件待确认。
